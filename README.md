# عيديات فنوميدو 🌙

تطبيق ويب احتفالي بثيم عيد الأضحى لتوزيع العيديات على العائلة.

## المزايا
- بطاقة لكل فرد من العائلة (فنو · ألما · أوس).
- سحب احتفالي للمبلغ مع عدّاد متحرك.
- عجلة ألوان دوّارة تختار لون عشوائي.
- تحدّي: شراء شيء بنفس اللون يكون خاصاً ومحبباً للنفس.
- كونفيتي وأصوات احتفالية بأجواء عيد الأضحى.

## التشغيل
افتح `index.html` مباشرة في المتصفح. لا يوجد build أو dependencies.
